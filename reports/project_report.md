# Sales & Revenue Analysis Report

## Objective
Analyze sales and revenue performance using transactional business data.

## Dataset Information
The dataset contains:
- product sales
- region details
- quantity sold
- profit metrics

## Tools Used
- Python
- pandas
- matplotlib

## Analysis Performed
- Data quality check
- Total sales calculation
- Profit analysis
- Regional revenue comparison
- Product performance analysis

## Key Insights
- Electronics generated the highest revenue.
- Regional performance differences are visible.
- Product-level analysis identifies top sellers.

## Business Impact
This dashboard-style analysis helps business teams make pricing, inventory, and regional sales decisions.
